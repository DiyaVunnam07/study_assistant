# AI-Powered Multi-Persona Study Assistant

An interactive study assistant built with Python, the Google GenAI SDK (`gemini-2.5-flash`), and Gradio. Users can ask any academic or technical question and switch between **Friendly** (analogy-driven, beginner-friendly) and **Academic** (formal, structured university-level) explanation styles.

## Tech Stack
- **Language:** Python
- **LLM SDK:** `google-genai` (`gemini-2.5-flash`)
- **UI Framework:** Gradio
